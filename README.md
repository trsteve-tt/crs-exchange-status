# CRS Exchange Status

A single generated page showing, for every partner jurisdiction, what Thailand
has sent under the CRS for reporting period 2025 and what has been received
back. Published so it can be read from anywhere.

**This repository is public and holds the page and nothing else.** It carries no
taxpayer data, no account or financial detail, no names, no file paths, no
hostnames and no transaction identifiers. The tool that produces the page, the
queries behind it and the operational detail it reads all stay in a private
repository and do not appear here.

`index.html` is regenerated from that tool and is self-contained: inline styles
and inline script, no external request of any kind. Figures are a point-in-time
snapshot and move through the day as transmissions are acknowledged.
